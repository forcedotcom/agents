    Type Alias PublishedAgentInfo

    Set as data.publishedAgent on an error thrown after the publish POST already committed a new BotVersion (for example, a failed metadata retrieve or authoring bundle deploy). Its presence means the version exists in the org, so the caller must not publish again.

    The reverse doesn't hold: a missing data.publishedAgent doesn't prove that nothing was committed. If the publish POST itself times out or returns a gateway error, Core may still have created the BotVersion. Re-query the agent's latest BotVersion before retrying in that case.
